# Moodboard · The Silent Divide

Moodboard web del trabajo de **Samuel Santiago Silva Largo** como modelador 3D en el equipo del videojuego *The Silent Divide* (Estudio de Creación 4).

Recorre los tres cortes del semestre: blocking de Umbira y Aurea, el cráneo coleccionable, los 18 props de alta calidad, el casco, Nero, el Núcleo, la animación de la tuerca y los renders de la escena, además de las diapositivas y la reflexión final.

Hecho con HTML, CSS y JavaScript, sin dependencias. Para verlo, abre `index.html` en el navegador.
